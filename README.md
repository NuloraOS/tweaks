# Твики

Готовые пакеты находятся в одной папке `debs/`: две камеры и Dock.

Источник Sileo: https://nuloraos.github.io/tweaks/

Это обычный APT-репозиторий, без сайта и оформления. В корне находятся Release и Packages. Для добавления в Sileo используется адрес источника выше, а не ссылка github.com.

Сборки для iPhone 5s / iOS 12 / Chimera. Реальная проверка на устройстве ещё требуется.
