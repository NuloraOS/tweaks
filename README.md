# Nelora — все твики

Одна общая страница и одна категория Tweaks в Sileo. Все три готовых DEB находятся вместе в корне репозитория.

Источник и страница: https://nuloraos.github.io/tweaks/

Nelora Camera (чёрно-белая), Nelora O2 Demo (для ролика), Dock. Glass и системный Motion больше не публикуются. Экспериментальные сборки для iPhone 5s / iOS 12 / Chimera; работа на устройстве требует проверки.
